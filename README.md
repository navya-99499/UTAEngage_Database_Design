# 🎙️ UTAEngage Database Design

This project presents a **complete database design and implementation** for a podcast platform, developed as part of academic coursework.

The system models real-world entities such as **students, podcasts, episodes, advertisers, and subscriptions**, ensuring data integrity through proper normalization and SQL constraints.

---

## 🧠 Project Overview

The project is divided into multiple phases covering the full lifecycle of database design:

-  Requirement Analysis  
-  EER Diagram Design  
-  Relational Schema Development  
-  SQL Implementation  

---

## 🔄 Workflow / Approach

### 1. Requirement Analysis
- Identified entities, attributes, and relationships  
- Defined business rules and constraints  

### 2. EER Diagram Design
- Designed entity-relationship model  
- Defined keys, relationships, and cardinality  

### 3. Relational Schema
- Converted EER diagram into relational tables  
- Applied normalization (up to BCNF)  

### 4. SQL Implementation
- Created tables using DDL
- Created triggers  
- Inserted data using DML  
- Implemented queries for data retrieval and updates
